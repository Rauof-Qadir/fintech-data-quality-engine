# FinSight — FinTech Transaction Data Quality Engine

## 🚀 Overview

FinSight is an automated financial transaction data-quality
pipeline designed to identify, analyze, clean, validate, and
monitor data-quality issues before downstream analytics and
machine-learning workflows.

Raw Transactions
        ↓
Schema Validation
        ↓
Data Quality Analysis
        ↓
Business Rule Validation
        ↓
Duplicate Detection
        ↓
Outlier Detection
        ↓
Automated Cleaning
        ↓
Validation
        ↓
Quality Report
        ↓
Streamlit Monitoring Dashboard
